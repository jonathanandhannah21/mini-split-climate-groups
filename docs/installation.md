# Installation Guide

## Via HACS (Recommended)

### Install Integration
1. Open HACS → Integrations
2. Click three dots → Custom repositories
3. Add this repository URL
4. Install "Mini Split Climate Groups"
5. Restart Home Assistant

### Install Card
1. Open HACS → Frontend
2. Click three dots → Custom repositories  
3. Add the same repository URL
4. Install "Mini Split Climate Card"
5. Clear browser cache

## Manual Installation

1. Copy `custom_components/mini_split_climate_groups` to your Home Assistant `custom_components` directory
2. Copy `www/mini-split-climate-card.js` to your `www/community` directory
3. Restart Home Assistant
