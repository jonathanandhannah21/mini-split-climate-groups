# Mini Split Climate Groups

Priority-based orchestration for multiple mini-split zones.

## Key Features

- Prevents heating and cooling simultaneously
- Priority-based mode control
- Detailed diagnostic logging
- Robust error handling for real-world issues

## Installation

Install via HACS as both:
1. Integration (Settings → Integrations)
2. Card (Dashboards → Resources)

## Quick Start

1. Add Integration: Settings → Integrations → Add Integration
2. Configure your climate zones
3. Add Card to Dashboard: Type `mini-split-climate-card`

For detailed documentation, see the [GitHub repository](https://github.com/yourusername/mini-split-climate-groups).
